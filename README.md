# 서울 진로진학 통합플랫폼 (SEN Portal) : UI 목업

학생·학부모·교사·정보원용 진로진학 통합 플랫폼의 HTML 목업입니다. 빌드 없이 정적 호스팅(GitHub Pages 등)으로 바로 동작합니다.

## 실행
- `index.html` 을 열면 메인에서 전 화면으로 이동합니다. (`main-everland-style.html`은 예전 주소용 자동 이동 페이지)
- GitHub Pages: Settings → Pages → Branch `main` / root 선택.
- 시연 기준일은 2027-09-01(수), 2028학년도 대입 일정입니다 (`sen-ledger.js` 한 곳에서 읽음).

## 공통 파일
- `sen-ledger.js` : 학년도·일정·세션·상담 시간·시연 기준일 원장, 용어 사전(개발 용어 → 쉬운 말), 조사 자동 선택
- `sen-marks.js` : 설계 검토 표시 [6open] [up1030] [school] [home] [의사결정](D1~D18) · 화면 맨 위 띠에서 끄기
- `auth.js` / `gnb.js` / `footer-sys.js` : 로그인 모달·역할·알림, 메뉴, 업무시스템 바로가기(정보원 역할만)

## 로그인·역할 (auth.js)
- IdP 3종 : 교육디지털원패스(L3) · 디지털원패스(L2) · 네이버/카카오(L1). 역할(학생·학부모·교사·상담교사·학교관리자·정보원)은 승인·위촉·학적 동기화로 부여.
- 교사·정보원 인증은 교육디지털원패스만 + 2단계 인증은 간편인증(네이버·카카오·PASS) 또는 휴대폰 6자리 (10-30 결정 D5). 전자서명이 필요한 업무(수능 성적 전송·정산 승인)만 GPKI.
- 모두 목업(localStorage) 데모 신원이며 실제 인증은 없습니다. 작업 기록은 `docs/`.
