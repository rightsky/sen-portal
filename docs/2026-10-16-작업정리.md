## 3. AI PoC 구성 변경
- 탭 순서 : **개인정보 원칙(기본 열림) · ① md 변환기 · ② 지식저장소(신규) · ③ RAG 어시스턴트 · ④ 생기부 AI 활용**. 포털 공통 시트(sen-ai.js)도 4카드 + 개인정보 원칙 링크, 캐시 키 `?v=20261016b`.
- **① md 변환기** : 「기본 지식 6편 불러오기」 삭제. 문서 선택·드롭 → md 변환만 하고 「저장 대기」 목록에 표시(지식저장소에 저장 · md 보기 · md 내려받기 · 복사 · 빼기, 「모두 지식저장소에 저장」). 「지식저장소 비우기」 유지(직접 저장한 문서만 비움).
- **② 지식저장소** : 저장한 문서가 모여 청킹·메타데이터·BM25 색인(5단계 카드는 삭제, 설명 한 줄). KPI + 저장된 문서 목록(md 내려받기 · 삭제). 세부 기능은 별도 기획 예정.
  - **기본 지식저장소** : 페이지 열면 기본 지식 6편 + `kb/2027-seoul-jeongsi-yogang.md`(2027학년도 서울 소재 대학 정시 모집요강 통합본 41개교 · 2116쪽 · 7.1MB) 자동 적재 → 7편 · 약 7,670청크 · 1.5초. 「기본」 배지, 삭제 가능(새로고침하면 복원).
  - 청킹 개선 : 코드블록(표) 펜스 제거·공백 축소, 중복 제거 키를 문서·섹션·본문 전체로, 역색인은 바뀔 때만 재생성(검색 ~14ms), RAG 근거 4 → 6청크. 통합본 기준일 오인식(OCR 문자열) 제거.
- **③ RAG 어시스턴트 : 혼합형** : 근거로 답할 수 있는 부분은 근거만·[번호] 인용, 부족하거나 무관한 부분만 `[일반 지식]` 문단으로 보충(노란 점선 상자 + 「일반 지식 · 출처 없음」 배지, 답 머리 「일반 지식 보충」). 근거 0건이면 전체를 일반 지식으로(「출처 없음」 안내). 일정·인원·반영비율 숫자는 근거 있을 때만. AI 미연결 시 「자료에 없음」. 지식저장소가 비면 ①로 안내(자동 적재 없음).
  - 화면 : 답이 오면 질문·답 머리가 보이게 스크롤(스트리밍 중 아래로 끌지 않음), 근거 카드는 접힘 상태 + 「근거 펼치기」(붉은 톤) · 인용 번호 클릭 시 펼침.
- **④ 생기부 AI 활용**
  - PDF 가져오기(doc2md·pdf.js, 브라우저 안에서만, 20MB) + 입력칸 드롭. 변환기 머리줄·md 기호 제거. 스캔·암호 PDF 안내.
  - 버튼 한 줄(입력칸 아래) : 「PDF · md 파일 가져오기」 「예시 데이터 불러오기 (합성)」 「모두 지우기」(연회색) → 「개인정보 가리고 시작하기 →」(연파랑). 글꼴·높이 통일, 모바일 세로 쌓임.
  - 긴 생기부 : AI에 보내기 전 `recCondense`로 인적·학적·출결·자격증·증명서 정보·성적표(| 표 |) 제거, 창체·세특·독서·행특만(실측 35,683 → 27,995자). 결과 카드에 보낸 글자 수·제외 항목 표시. 가상 기록 생성도 같은 원문으로 6,000자 이내.
  - 비식별 보강 : 담임성명 표, 주민번호 뒷자리 `*` 형식, 문서확인번호·대장번호, 신청인. 「담임성명」 표 제목을 이름으로 오인하던 문제 수정. 세특 본문 속 타 학생 이름은 규칙으로 못 잡으므로 1단계 화면 확인 필요.
- 예시 체험 카드 : 「처음부터 끝까지 자동 실행」 삭제, 단계별 버튼(①·③·④) 유지. 체험 안에서만 기본 지식 6편을 씀.
