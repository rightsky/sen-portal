# 외부 단말 S존 접속 체계(ZTNA + 단말검증 + MFA + RBI) 예산안 검토와 수정본 (2026-11-02)

용도 : '27 RFP 예산 근거. 사용자가 받은 「500명 기준 ZTNA · RBI 통합 구축 예산 시뮬레이션」을 검토해 고친 것. 금액 상세는 엑셀 「외부접속-ZTNA-RBI-예산내역-2026-11-02.xlsx」. 관련 : claude/타시도교육청-활용방안-2026-11-02.md(접속 방법 표), claude/RFP-추가요구사항-인증·O존-2026-11-02.md(SFR-AUTH-03), claude/설계전제-오픈시기-망분리-2026-10-30.md(신청자 RBI 300명).

## 1. 접속 경로와 이 예산의 범위 (사용자 질문 3건의 결론)
- ZTNA + 단말검증 + MFA + RBI는 「집(외부 단말)에서 S존을 보는 유일한 허용 경로」(N2SF 모델 9)다. 이 조합을 갖춘 신청자는 집에서도 담당 학급 화면을 볼 수 있고, 화면만 전달되며 파일 저장 · 복사 · 캡처는 막힌다.
- 이 조합은 S존 접속의 기본이 아니라 외부 단말에만 붙는 조건이다. 학교 · 정보원 업무망 PC는 교육청이 관리하는 S등급 단말이라 ZTNA · RBI 없이 통합인증 로그인 + (식별 화면 진입 때) 2단계 인증이면 된다.
- 업무망 PC에서 S존은 「로그인 + 2단계」다. 2단계 인증(누가 권한을 행사하느냐)과 ZTNA · RBI(어느 단말에서 들어오느냐)는 다른 장치다.
- 따라서 ZTNA · RBI 라이선스 수는 전체 교사가 아니라 「집에서 S존을 보겠다고 신청한 교사」 수다. 설계 전제는 300명(진학부장 · 3학년 담임 · 위촉 상담 선생님 우선), 예산안은 여유를 두어 500명.

## 3. 수정 예산안 요약 (부가세 별도, 초기 도입 1년 차)
| 구분 | SW 라이선스 | 구축 · 연동(SI) | 소계 |

| 공통 SI(원패스 연계 · S존 화면 연동 · 감사 로그 · WAF 연동 · 에이전트 배포 · 교육) | | 1,500~2,500 | 1,500~2,500 |
| 합계(지정 500 기준) | 11,000~16,500 | 8,000~13,000 | 19,000~29,500 |
| 합계(동시 150 대안) | 9,000~13,500 | 8,000~13,000 | 17,000~26,500 |
단위 만 원. 발주 편성 권고 : 지정 500 기준 2.2~2.5억(부가세 별도), 동시 150 대안 2.0~2.3억. 기존 NAC · VPN 재활용 시 ZTNA 쪽 2,000~4,000만 원 절감 가능.

2년 차 이후 연간 : SW 유지관리 10~15%(1,100~2,475만 원) + 인프라 유지보수 300~500만 원 = 1,400~3,000만 원.

구독형 비교(설계 전제) : 300명 × 연 5~15만 원 = 연 0.15~0.45억, 초기 구축비 없음(SI 공통분 1,500~2,500만 원은 동일). 3년 누적으로 보면 구축형 2.4~3.5억 vs 구독형 0.6~1.6억이나, 구독형은 클라우드 RBI(SaaS)라 S존 자료가 외부 서비스 구간을 지나므로 공공 클라우드 보안 인증(CSAP)과 N2SF 등급 판정을 따로 받아야 한다. 심의 부담을 고려하면 구축형이 기본, 구독형은 CSAP 상 등급 제품이 있을 때 대안.
