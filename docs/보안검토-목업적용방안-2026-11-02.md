# 보안 아키텍처 준수 검토 v1 → 목업 적용 방안 (2026-11-02)

입력 : 「통합포털 목업 보안 아키텍처 준수 검토 v1」(2026.11.02, index · teacher · my · parent · counsel 5화면, N2SF 가이드라인 1.0 모델 1·4·8·9·11 기준). 이 문서는 검토의 판정 하나하나를 지금 목업의 어느 화면·문구로 받을지 정한 설계안이다. 사용자가 확인하면 그대로 반영한다. 실제 망 구성·인증 연계는 목업이 흉내만 내므로, 목업에서는 「어느 존의 화면인지」 「어떤 경로로 들어가는지」 「무엇을 내려보내지 않는지」가 화면에 보이게 하는 것이 목표다.

## 0. 요약
- 구조 변경 1건 : 교사공간을 O존 포털 화면(teacher.html)과 S존 교사 업무 화면(teacher-school.html, 새 파일)으로 나눈다. 포털에는 건수·링크·상담 준비만 남기고, 학생 한 명을 가리키는 행이 있는 화면(우리 반 · 수시/정시 · 환산점 · 판정 확인 · 비교·분석 · 학생상담모드 · 상담 이력 · 공유 자료 · 감사로그 · 학교 관리)은 모두 S존 화면으로 옮긴다. 지금의 「학교 업무망 / 집 인터넷」 전환 단추는 없앤다.
- 문구·흐름 변경 13건 : 전문시스템 진입 경로, 학생부 읽기 도우미 위치, 설치형 쎈진학 폐쇄 일정, 교사 자료 「가공 예시」 표기, 열람 사유 자동 + 변경, 집 모드 업무 코드 1:1, 학부모 성적 추이 opt-in, MY O존 비저장 규칙, 통합인증 연계 문구, 기존 상담 사이트 폐쇄 일정, 사전자료 수신 S존 문구, 게시판 상담 입력 통제, 메인(유지).
- 결정이 바뀌는 것 : D4(교사공간 구조)는 이 검토로 「S존 분리형」으로 닫을 수 있음. D11(학부모 성적 추이 기본 공유)은 재검토 대상(★ opt-in). D3(교육청 통일)·D6(식별 화면 진입 때 2단계)은 검토 결과와 같은 방향이라 그대로.
- 표시 : 이번 검토로 바뀐 곳은 새 표시 [보안1102]로 달고, [school] 뜻을 「S존 화면(교육청 업무망, 별도 접속)」, [home]을 「O존 포털(인터넷)」로 고쳐 적는다.

### 3-2. 지금 구조에서 바뀌는 것
- 상단 「학교 업무망 / 집 인터넷」 전환 단추와 집 모드 이름 가림(homeMask) 삭제. D4 [의사결정] 표시는 「S존 분리형으로 종결(보안 검토 2026-11-02)」로 바꿈.
- 포털 교사공간 탭 5개 → 홈 · 상담 준비 · 통계 · 배정 답변 · 자료 + 오른쪽 「업무망 화면 열기」 단추.
- 포털 홈 할 일 묶음에서 학생 이름이 있는 줄(상담 요청 · 공유 승인 · 판정 확인 학생별)은 건수 한 줄로 바꾸고 「상세 ›」가 진입 창을 연다.
- 정보원 상담시스템 · AI 서비스 관리 · 플랫폼관리(ops-*)는 이미 별도 페이지 + 진입 게이트 구조라 띠 문구만 S존 형식으로 맞춘다.
- 사용자 PC 시연 방법(README · 엑셀 로그인방법) : 「교사공간에서 업무망 화면 열기 → 경로 ① 선택 → 간편인증 → 새 창」.

## 3-4. 합성 · 재현데이터로 O존을 넓히는 기준 (사용자 지시 2026-11-02 : 보안상 문제가 없는 한 O존으로 최대한)
- 넘길 수 있는 것 : 비교·분석 배경 분포(3개년 입결 합성) · 진학통계 학교 간 · 학년 간 비교와 졸업생 결과 · 상담 준비 가상 프로필 · 사례 묶음 · AI 학습 · 회귀 시험 · 연수 · 시연 · 학생 입시결과 비교의 배경. S존의 「반 전체 분포」류는 합성 · 억제 처리해 O존 집계판으로.
- 넘길 수 없는 것 : 판정 확인 · 학생별 지도 · 학생별 환산점 · 학생상담모드 · 상담 이력 · 공유 자료 · 열람 기록(목적이 실제 그 학생). 「우리 반」 단위 합성은 역산 위험과 상담 부적합으로 금지, 반 단위는 건수 · 5명 미만 억제 집계로만.
- 조건 : ① 가명이 아니라 익명(O존에 작업 번호 + 상세 속성 조합 금지) ② 생성은 S존에서, 익명성 평가(k-익명성 · 소집단 억제 · 역산 위험) 통과분만 CDS로 ③ 단위는 학교 · 학년 · 교육청 이상, 5명 미만 셀 억제, 희귀 조합 제거 ④ 「합성 · 실제 학생 아님」 표시, 개인 상담 판단 근거로 사용 금지(법적 경로 B) ⑤ 재현데이터와 합성데이터는 따로 관리(10-14 결정), 재현데이터는 익명성 평가 문서가 있을 때만 O존.
- 1단계 집계판 설계에 반영 : S존 view마다 O존용 집계판(반 관리 → 적재 상태 · 공유 동의 건수, 수시/정시 → 전형 유형별 장수 분포 · 최저 충족 예상 비율(억제), 판정 확인 → 대기 명수, 상담 이력 → 유형별 건수, 학교 관리 → 승인 대기 건수)과 「학생별 보기 › 업무망 화면」 링크.
