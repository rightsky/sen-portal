### 1-3. C. 요약 : 우선 수정 10건

1. **반 실데이터 보관 위치 15곳**(DAR-004 · SFR-015 등) : 담임 2옵션 → 교육청 저장소 단일. 산출물 「PC 암호화 컨테이너 규격서」 삭제. 가장 넓게 퍼진 충돌.
2. **교사공간 정의와 SFR-014~022 재배치** : 「통합포털 안의 영역」 → O존 교사공간(건수 · 링크) + S존 교사 업무 화면 분리. SFR-NEIS-03 신규와 함께.
3. **인증 체계**(SFR-002 · SFR-014 · INR-001 · SER-001 · SFR-044 · Ⅲ.2) : 원패스 단일 + 2단계는 간편인증 · 휴대폰, GPKI는 전자서명만. 1차 오픈 소셜 로그인 과도기 결정 필요. SFR-AUTH-01 · 03 반영.
4. **외부 단말 접속 체계**(SER-001 · ECR-006 · Ⅰ.1 사업금액 ※) : ZTNA · 단말검증 · MFA · RBI 경로 확인 요건 추가, 솔루션은 발주기관 별도 도입으로 명시.
5. **NEIS 업로드 보안 통제 신규**(SFR-NEIS-00 · 01 · 02) : 메모리 처리, 파기 안내 · 감사 로그, 학교 참여 승인 · 동의 명단 대조. INR-002 무결성 게이트에 범위 · 동의 검사 추가.
6. **정책값 4종 일괄 수정** : 예비 슬롯 수락 24h → 48h(Ⅲ.7), 게시판 답변 48h → 배정 후 24h(4곳), 업무시스템 세션 15분 → 30분(5곳), 학생상담모드 10분 종료 → 20분 잠금 · 자동 종료 없음(4곳).
7. **멀티테넌트 신규**(SFR-TNT-01) + Ⅱ.3 조직별 역할표에 발주기관 협조 사항(원패스 「전국」 신청 · 타 교육청 협약 · 동의 수집 · 단말 인프라 운영).
8. **O존 비저장 · 게시판 입력 통제**(SFR-PTL-01을 SFR-006 · 010 · 012 · 035에 분산 반영) 및 **O존 집계 기준**(SER-007 · DAR-001 · DAR-005에 5명 미만 · 2차 억제 · 차원 제한 · 익명성 평가 조건).
9. **번호 · 용어 정합** : TER 총괄표 007 누락 복구, 역할 6종 vs 7역할, 생기부 3곳 → 학생부, AI 입구 「진로진학 AI 챗봇」 통일, 「판정 승인」 vs 「판정 확인」 · 「미래탐색」 명칭 확인.
10. **삭제 결정 반영과 오타** : 우선점수 P1~P6, 전화 채널, 1단계 STT 동의 · 시험 문구 제거 ; 「컮럼」 · 「플랫웬관리」 · 조사 오류 16곳 · 날짜 형식 통일.

## 4. 사용자 확인 사항
1. RFP 신규 10건을 「기존 번호 세부내용 추가」로 넣을지 「신규 번호」로 넣을지(1-1 표의 권고대로 할지)
2. 온북 Case 4를 v1.3에서 「참고」로 격하하는 것(10-30 결정과 일치)
3. 목업 2-2의 3번(NEIS 업로드 화면)과 7번(타 시도 테넌트 시연)을 이번에 할지
4. 집 모드 업무 코드 대응표(H-xx ↔ A~E), 접근통제 설계서 절 번호
5. 외부 접속 예산을 RFP 본문에 넣을지, 발주기관 별도 발주(장비 · 상용 SW)로 둘지(현재 RFP 1절은 상용 SW · 장비를 별도 발주로 둠)
6. 담임 반 실데이터 보관 위치 2옵션(PC 보관 / 교육청 저장소)이 RFP 15곳에 남아 있음 : ★ 교육청 저장소(S존) 단일로 통일하고 「PC 암호화 컨테이너 규격서」 산출물 삭제(1-2-1 ⑦)
7. 1차 오픈(6월)에 교육디지털원패스 미적용이면 과도기 소셜 로그인 · 회원 저장이 불가피함 : 과도기 범위와 종료 시점을 SFR-002에 명시할지, 1차부터 원패스로 갈지(1-2-1 ③ · 1-2-2 ㉒)
8. 명칭 확인 3건 : 「판정 승인(HITL)」 vs 목업 「판정 확인」, 「미래탐색」 vs 「진로탐색」, 「지원가능성 참고분석」 잠금 카드 유지 여부(1-2-2 ⑱~⑳)
9. RFP 정책값 4종 일괄 수정 승인 : 예비 슬롯 수락 24h → 48h, 게시판 답변 48h → 배정 후 24h, 업무시스템 세션 15분 → 30분, 학생상담모드 10분 종료 → 20분 잠금(1-3 ⑥)
