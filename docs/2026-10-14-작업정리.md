## 3. 통합 적용 1~5단계 (SEN 진학프로그램·상담시스템 → 포털)
결정(10-14) : 인증은 **B안(교육디지털원패스 + Step-up 2FA) 기본, A안(GPKI) 비교용 스위치** · 승격 화면은 교사 측 + 학교관리자 승인함만(정보원 운영 콘솔 제외) · 의견 수집 폼 없음.

| 단계 | 내용 | 파일 | 확인 방법 |
| --- | --- | --- | --- |
| 1 | 통합 로그인·회원가입·공통 역할 상태 : IdP 3종(교육디지털원패스 L3 / 디지털원패스 L2 / 네이버·카카오 L1), 데모 신원 11종, 회원가입 4단계(동의 2종), Step-up 2FA 모달, 헤더 역할 배지·역할 전환(상담교사·학교관리자·정보원은 2FA), 세션 `sen-auth-v2`(레거시 `sen-trait-state` 동기화), 메인 역할별 안내 띠 | auth.js(재작성), index.html, parent.html | 아무 화면 헤더 「로그인」→ IdP 선택 → 데모 신원 |

## 남은 것 (코드보다 결정·확인이 먼저)
1. 학교 편제표 입력 방식 : 학교 담당자 입력 / 나이스 연계 / 정보원 일괄 → 통합 2단계 학교 관리(③ 학생 매핑)와 같은 화면에서 설계
2. 실제 대학명 사용 : 어디가 50개 대학 발표 반영 여부, 연도 갱신 책임 → `OV`·수시/정시 지도 예시 데이터 교체
3. 자료집 재가공 승인 범위 : 공공누리 4유형 표시와 판권면 "승인 없이 이용 불가" 병존 → 정보원 확인
4. 기본 학점 처리 : 학교별 운영 학점 반영 여부 → 1번과 묶음
5. 공식 URL 확인 : jinhak.or.kr vs jinhak.sen.go.kr·ipsi.sen.go.kr → 확인 즉시 일괄 교체
6. 진로검사 문항 수 : H형 130·가치관 28 vs 자료집 126·49 → 커리어넷 현행 확인
7. (통합) 전문시스템 SSO 방식과 열람 사유 코드 체계, 상담 학기 1회 한도의 "교사 추천 경로" 화면, 나이스 보호자 대조 API 가능 여부 → 실무 교사 의견 수렴 뒤 결정
