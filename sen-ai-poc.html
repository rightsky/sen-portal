지식베이스 구축

md 파일을 등록하면 아래 5단계로 지식DB를 만듭니다. 처리는 모두 이 브라우저 안에서 끝나고, 결과는 이 기기에만 저장됩니다.

1
파일 수신.md만 허용 · 파일명·크기 확인
2
청킹제목(#·##·###) 단위로 자르고 400자 넘으면 문단으로 재분할
3
메타데이터 추출출처 파일 · 섹션 경로 · 학년도 · 기준일(본문에서 자동 탐지)
4
인덱싱한글 2-gram + 단어 토큰 BM25 역색인
5
검증 · 활성화중복 청크 제거 · 건수 확인 · 저장

생기부 어시스턴트

생기부(세특·창체·행특) 텍스트를 붙여 넣거나 .md 파일을 올리면 ① 비식별 처리 → ② 가명/합성 데이터 생성 → ③ 3대 역량 분석 순으로 진행합니다. 원본은 저장·전송되지 않습니다.

1
비식별 처리 (브라우저 안)이름·학교·학번·주민번호·연락처·주소·이메일·생년월일 탐지 → 토큰 치환
2
가명데이터 또는 합성데이터가명 = 식별자만 바뀐 원문 · 합성 = 구조만 같은 새 기록(AI 생성)
3
3대 역량 분석학업역량 · 진로역량 · 공동체역량 기준 · 좋은 기록/아쉬운 기록 · 보완 제안

개인정보 원칙 (이 PoC가 지키는 것)

단계원칙구현
입력원본은 서버에 보내지 않는다파일은 브라우저 FileReader로만 읽고, 네트워크 호출 없음
비식별직접 식별자는 AI 호출 전에 제거이름·학교·학번·주민번호·연락처·주소·이메일·생년월일 규칙 치환 + 결과 화면에서 사람이 확인
AI 호출가명 또는 합성 텍스트만 전달sample 호출 입력에 원문 변수를 쓰지 않음(코드 수준 분리)
저장생기부는 저장하지 않는다localStorage에는 지식DB(md)만 · 생기부·분석 결과는 새로고침 시 소멸
표시원천을 문자로 구분실데이터 가명데이터 합성데이터 배지 (색 + 문자)
판단AI는 확정하지 않는다"AI 계산 · 출처 보기"만, "AI 의견" 라벨 없음, 기재 결정은 교사

운영 전환 시: 비식별은 S존 안 서버 배치(가명처리·k-익명성·DP), 합성 생성 주체는 SEN 단일, 원본은 요약 뒤 즉시 삭제. 이 PoC의 규칙 치환은 데모용 1차 필터입니다.

어떤 서비스를 이용하시겠어요?

SEN AI는 지식DB를 근거로 답하는 대화형 서비스와, 생기부를 비식별 처리한 뒤 3대 역량으로 읽어 주는 어시스턴트로 나뉩니다.

AI 응답은 참고 자료이며 선생님 확정 뒤에만 판단이 됩니다.
